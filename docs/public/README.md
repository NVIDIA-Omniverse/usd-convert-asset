# USD Convert Asset documentation

`usd-convert-asset` provides native C++ libraries, Python bindings, a
command-line interface, and USD plugin resources for converting common 3D asset
formats into USD.

Public documentation is maintained in these repository locations:

- [`README.md`](../../README.md): overview, requirements, build instructions,
  usage examples, compatibility guidance, and support information.
- [`source/python/README.md`](../../source/python/README.md): Python package and
  command-line usage.
- [`external/omniverse-asset-converter/include/usd_convert_asset.h`](../../external/omniverse-asset-converter/include/usd_convert_asset.h):
  native public API declarations.
- [`CHANGELOG.md`](../../CHANGELOG.md): release history.
- [`SECURITY.md`](../../SECURITY.md): vulnerability reporting instructions.

This directory provides an index of the project's public documentation. Public
API, compatibility, behavior, or support changes should update the relevant
documents above as part of the same reviewed change.
